# Horse Course Suitability System

競馬の過去データを蓄積・分析し、レース条件に対する馬の適性を検索・比較・ランキングするデータ分析システム。

## 概要

本システムは、競馬の勝敗を断定する予測AIではなく、過去のレース結果をもとに、

- 今回のレース条件に対して、過去にどのような馬が好走しているか
- 今回の出走馬の中で、過去データから条件への適性がありそうな馬はどれか

を検索・分析することを目的とする。

初期段階ではルールベースで適性を評価し、将来的には機械学習による分析へ発展させる。

## 主な機能

- 馬のプロフィール登録
- レース情報登録
- レース結果登録
- 過去レースデータの検索
- レース条件別の適性分析
- 出走馬の適性ランキング
- 適性評価の根拠表示
- 過去の好走傾向の分析
- 類似条件の検索
- データ集計・更新

## システム構成

### MySQL

競馬データの原本を保存する。

- 馬
- レース
- 出走情報
- レース結果
- プロフィール
- 各種履歴

### Elasticsearch

検索・分析用途として利用する。

- 条件検索
- 過去レース検索
- 類似条件検索
- 分析用データ検索

### Spring Batch

大量の過去レースデータを対象とした、

- 成績集計
- 条件別集計
- 分析用データ作成
- Elasticsearchへのデータ更新

などに利用する。

## 適性分析について

分析対象となる馬は、原則として過去3レース以上のデータを持つ馬とする。

データが不足している馬については、無理に低い順位を付けるのではなく、

「分析対象外」
「データ不足」

として扱う。

適性評価では、例えば以下の要素を利用する。

- 競馬場
- 芝 / ダート
- 距離
- 馬場状態
- 枠順
- 脚質
- 上がり3F
- 近走成績

評価は初期段階ではルールベースで行い、将来的に過去データから重みを学習する機械学習へ発展させる。
